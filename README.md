#### 简介
使用c#实现一个win免安装、不联网的小工具应用

主要功能
1. 把视频转成各个帧图片--图片会比较多
2. 图片去重：把指定文件夹下的所有图片进行去重并可删除重复图片
3. 图片分类：识别图片内容，比如把图片中包含人的图片挑出来，移到指定路径下
4. 文件大小工具：判断单个文件或者指定文件夹下各个文件大小或指定大小的文件
5. 智能闹钟：设置指定时间闹钟，并按照指定文案来语音播报提醒
6. 实时人流统计：对接摄像头，实时统计摄像头中各个时间段内的人流并记录到指定文件中
	开始统计按钮，会每隔10秒统计一次
	停止统计按钮，只有开始统计按钮点击置灰后，该按钮才可点击。
	点击之后，10一次的定时停止执行，并把数据写到data/monitor.txt中，这是开始统计按钮才可再次点击
7. 增加录屏功能
